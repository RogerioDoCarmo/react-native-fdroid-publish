# The build mirror

An Expo managed app has no committed `android/`: `expo prebuild` generates it. F-Droid's build
server wants a repository it can build with plain Gradle. The **build mirror** is that repository:
a public, build-only snapshot regenerated by a workflow in the source repo on every release, and
never edited by hand.

| Repository | Role |
| --- | --- |
| `<app>` | the real project; holds the mirror workflow |
| `<app>-android` | the mirror F-Droid builds from (`Repo:` in the recipe) |
| fork of `fdroid/fdroiddata` on GitLab | carries the recipe; its merge request is the submission |

Bare React Native projects with `android/` committed can skip the mirror (see
`project-sheet.md`).

## What the mirror contains

- the generated `android/` project;
- the JS source, assets, config files and local modules Gradle's bundling step needs;
- `package.json` and the lockfile, **not** `node_modules`: the recipe installs at build time;
- `.npmrc` with `node-linker=hoisted`;
- `fastlane/metadata/android/<locale>/`, which F-Droid reads for the listing;
- `patches/`, `LICENSE`, `PRIVACY.md`.

Tests, stories and local Gradle state stay out: a tree the scanner reads should be build-only.

## The workflow

Start from [../templates/android-mirror.yml](../templates/android-mirror.yml) and
[../templates/assemble-mirror.sh](../templates/assemble-mirror.sh). In order, it:

1. checks out the **release tag** (the variant and the patches belong to that tag's lockfile);
2. derives `versionName` and `versionCode` from the tag and refuses a mismatch with `app.json`;
3. installs, then `pnpm remove`s the variant's excluded packages (so the lockfile drops them);
4. writes the variant into `package.json`, adds `buildFromSource: [".*"]`, drops the `prepare`
   script (husky), strips `updates`/`runtimeVersion` from `app.json`;
5. runs `expo prebuild --platform android --no-install` with the variant set;
6. **refuses to push** when the generated project or the lockfile still names Firebase, GMS,
   ML Kit, the install referrer or `expo-updates`;
7. assembles the snapshot, sets the real `versionCode`/`versionName`, writes `.npmrc` and Fastlane;
8. `rsync --delete`s it into the mirror, keeping the mirror's `README.md` and `.gitignore`, commits,
   tags, pushes, and prints the **commit hash** in the job summary.

It costs nothing: GitHub-hosted Ubuntu, no binary built, nothing distributed.

## Rules learned the hard way

- ⚠️ **`node-linker=hoisted`.** F-Droid's scanner resolves real paths; pnpm's default layout puts
  every package under `node_modules/.pnpm/<name@version_hash>/`, which no recipe can name stably
  (every `scanignore` entry reported "Unused"). Hoisted gives flat, symlink-free paths.
- ⚠️ **`versionCode` from the tag.** Outside EAS, prebuild writes a placeholder `versionCode 1`.
  Rule: `major*10000 + minor*100 + patch` (`v1.3.1` → `10301`); minor and patch must stay below
  100. A `-prerelease` tag is refused: F-Droid would publish it as the real version.
- ⚠️ **Same-version re-release tags.** If the project tags `v0.3.7+appstore` for a store-only
  rebuild, mirroring it automatically would re-point the mirror's `v0.3.7`. Mirror only plain
  `vX.Y.Z` on release; mirror a `+metadata` tag by dispatch, on purpose. The mirror tag drops the
  metadata (`v0.3.7+fdroid` → mirror tag `v0.3.7`).
- ⚠️ **Re-mirroring rewrites the hash.** A re-run makes a new mirror commit and force-moves the tag;
  the recipe's `commit:` must be updated from that run's summary.
- ⚠️ **Packaging from the tag vs from `main`.** Miroji took its patches from `main` (they were
  tooling, written after tags). Once the variant is app source, take everything from the tag, so
  the patches match that tag's lockfile.
- ⚠️ **`workflow_dispatch` needs the workflow on the default branch.** A first mirror of an existing
  tag waits until the workflow has been promoted to `main`.
- ⚠️ **`gradle-daemon-jvm.properties`.** Android Studio writes it with a toolchain pin; delete it from
  the snapshot (and locally, if a non-x86_64 build breaks).
- ⚠️ **Generate Fastlane from one source.** Miroji hand-wrote Fastlane in the mirror and protected
  it from sync; OmniMorse generates it from the store listing files on every run, swapping the
  privacy paragraph for an F-Droid one and failing when the store paragraph changes. Keep older
  `changelogs/` out of the `--delete` (F-Droid keeps showing them).

## Fastlane

Path: `fastlane/metadata/android/<locale>/` with `title.txt` (≤ 50), `short_description.txt`
(≤ 80), `full_description.txt` (≤ 4000), `changelogs/<versionCode>.txt` (≤ 500), and
`images/icon.png`, `images/featureGraphic.png`, `images/phoneScreenshots/*.png`. Limits are from
F-Droid's [descriptions page](https://f-droid.org/docs/All_About_Descriptions_Graphics_and_Screenshots/);
test every locale against them.

- Use the locale F-Droid's client matches: plain `es`, not `es-419`, because every Spanish phone
  falls back to `es`.
- Copy must describe **the F-Droid build**: no crash-report switch, no store-only features, and a
  privacy paragraph that matches it. Leave out screenshots that show removed features.

## The mirror repo and its token (owner's steps)

1. Create `<owner>/<app>-android`: public, `main` branch, a `README.md` stating it is generated and
   not to be edited, a `.gitignore`. The sync leaves those two alone.
2. Create a **fine-grained personal access token** with **Contents: read and write** on the mirror
   repo only, and store it as a secret in the source repo (`gh secret set <APP>_ANDROID_TOKEN`).
   The token is typed by the owner; check the secret exists by name with `gh secret list`.
3. Release, or dispatch the workflow with an existing tag.

## Verify a run by cloning, not by the green tick

```bash
git clone --depth 1 https://github.com/<owner>/<app>-android /tmp/m && cd /tmp/m
git rev-parse HEAD; git rev-parse 'vX.Y.Z^{commit}'           # the same hash, the one for the recipe
grep -n 'versionCode\|versionName' android/app/build.gradle
cat .npmrc; node -p "require('./package.json').expo.autolinking"
grep -nE 'firebase|expo-updates|mlkit|installreferrer' package.json pnpm-lock.yaml || echo clean
ls fastlane/metadata/android/
```

⚠️ The mirror's **main** `AndroidManifest.xml` may still list `INTERNET`; the release overlay
(`android/app/src/release/AndroidManifest.xml`, `tools:node="remove"`) removes it. Check the
overlay, and the APK.

## Done

A mirror run is green and the clone check shows the right hash, version, `.npmrc`,
`buildFromSource`, Fastlane locales, and no excluded package.
